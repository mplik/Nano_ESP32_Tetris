# ESP32 Nano Tetris

Klasyczna gra Tetris na Arduino ESP32 Nano z wyświetlaczem OLED i joystickiem.

## Komponenty
- ESP32 Nano
- OLED SSD1306 128x64
- Joystick analogowy 2-axis
- Buzzer 5V aktywny
- Płytka Protoboard - DFRobot

## Sterowanie
- Lewo/Prawo: joystick poziom
- Dół: przyspieszenie
- Przycisk: obrót

## Funkcje
- High score w EEPROM
- Efekty dźwiękowe
- Kolizje i animacje
